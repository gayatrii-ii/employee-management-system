# Employee Management System (EMS)

A full-stack inspired frontend application for managing workplace tasks, tracking employee performance, and streamlining administrative duties.

## 🚀 Overview
This system provides two distinct interfaces: an **Admin Dashboard** for task assignment and oversight, and an **Employee Portal** for progress tracking. Built with a focus on seamless state management and a clean, Gen Z-inspired digital aesthetic.

## ✨ Key Features
- **Role-Based Authentication:** Dedicated login flows for Administrators and Employees.
- **Task Management:** Admins can create, assign, and track the status of multiple tasks.
- **Real-Time Counters:** Visual status cards for "New Tasks," "Completed," "Accepted," and "Failed" tasks.
- **Persistent Data:** Leverages LocalStorage to ensure data persists across browser sessions.
- **Responsive UI:** Styled with Tailwind CSS for a modern, mobile-friendly experience.

## 🛠️ Tech Stack
- **Frontend:** [React.js](https://reactjs.org/) (Vite)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** React Context API / Hooks
- **Storage:** Browser LocalStorage

## 📂 Project Structure
- `/src/components`: Reusable UI elements like Task Cards and Headers.
- `/src/context`: Logic for handling global employee and task data.
- `/src/utils`: Helper functions for initializing LocalStorage data.
